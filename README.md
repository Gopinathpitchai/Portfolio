# Gopinath P - Modern Animated Personal Portfolio

A sleek, responsive, cyber-modern portfolio web application built with **React.js**, **Vite**, and custom **Vanilla CSS** animations for **Gopinath P** (Frontend Developer & MCA Candidate @ Kalasalingam University).

---

## 🚀 Key Highlights & Features

- **Executive Portrait & Hero**: Studio coat suit portrait in an animated rotating neon cyber ring, typewriter role switcher, and quick-copy contact chips.
- **About Me**: Core engineering pillars covering Frontend Craftsmanship, ERP & Business Workflows, Databases, and AI/ML.
- **Skills Matrix**: Categorized filter tabs (Frontend, Programming, Databases, Tools, Soft Skills) with animated progress bars.
- **Projects Showcase with Deep-Dive Modals**:
  1. *Manufacturing ERP System* (Python, SQL, ERP Frameworks, DocTypes)
  2. *Medical Healthcare AI Chatbot* (Python, ML, Kaggle Datasets, NLP)
  3. *Smart Bus Tracking Mobile Application* (React Native, JavaScript, Real-Time Maps)
- **Education Timeline**: Illuminated vertical milestones for MCA (2025–2027), BCA 8.1 CGPA, and HSE.
- **Interactive Contact**: Copyable email & phone number with instant toasts, plus a message form with celebration confetti!
- **Printable Resume Modal**: Clean, executive formatted resume view with a one-click Print / Save as PDF action.

---

## 🛠️ Tech Stack

- **Framework**: React 19 & Vite
- **Styling**: Vanilla CSS (Custom tokens, Glassmorphism, CSS Keyframes, CSS Grid & Flexbox)
- **Icons**: Lucide React
- **Effects**: Canvas Confetti & Interactive HTML5 Canvas Particle Background

---

## 💻 Local Development

```bash
# Clone the repository
git clone https://github.com/Gopinathpitchai/Portfolio.git

# Navigate into project directory
cd Portfolio

# Install dependencies
npm install

# Start development server
npm run dev

# Build for production
npm run build
```

---

## ☁️ Deployment on Vercel

This repository is pre-configured for seamless 1-click deployment on **Vercel**:
1. Framework Preset: **Vite**
2. Build Command: `npm run build`
3. Output Directory: `dist`
